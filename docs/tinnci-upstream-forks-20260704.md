## Notes

- The `sdm845-linux-next` local shallow branch push failed because GitHub
  rejected the shallow history boundary with a missing expected object. The
  snapshot workflow avoids this by generating root commits from the checked-out
  trees.
- The canonical patch review line for the mainline kernel remains the `G9650`
  control repo. The snapshot mirror is for browser access, branch pinning, and
  GitHub-side archival of the exact source tree.
